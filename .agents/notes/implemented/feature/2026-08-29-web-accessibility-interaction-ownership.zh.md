# Agent Note: Web 无障碍交互职责归属

Status: implemented

[English](2026-08-29-web-accessibility-interaction-ownership.md) | 中文

## Problem

若干 Web 共享控件暴露了无障碍 role，却没有实现这些 role 所承诺的键盘与焦点行为。模态弹窗不约束或恢复焦点，菜单把菜单项暴露成普通的独立控件，Workspace 与 Session 树没有复合控件键盘模型，折叠搜索仍在无障碍树中保留输入框且没有明确的焦点返回约定，布局分隔条只能使用指针操作，应用缺少稳定的具名地标，已经关闭但仍挂载的详情子树继续接受键盘导航，上下文占用率还把非模态 disclosure 描述成 dialog。Companion 插件可以诊断渲染后的标记，但无法在渲染后安全重建组件状态、焦点职责或嵌套关闭时序。

## Decision

拥有交互的核心组件同时拥有其无障碍行为。可选无障碍插件通过已声明 slot 提供诊断、指引、偏好与内容创作辅助；它们不通过观察 DOM 重写核心交互语义。这一分工遵循 [slot 组合决策](../architecture/2026-07-22-slot-type-chain-implementation.zh.md)：替换级行为留在拥有该 slot 的组件中，增量行为通过已声明的子 slot 注册。

共享 `Modal` 基础组件维护已打开弹窗的栈；栈非空时使 `#root` 进入 inert 状态；选择初始焦点；约束正向和反向 Tab 遍历；只允许最上层弹窗响应 Escape 与遮罩关闭；并把焦点还给仍连接在文档中的打开控件。没有可 Tab 子元素的弹窗把焦点保留在 dialog 容器。可见标题可以通过 `aria-labelledby` 为 headless 内容命名，普通模式继续保留本地化的关闭控件。

共享 `Menu` 基础组件为内联触发控件实现菜单按钮关系，也接受外部渲染触发控件所需的显式名称与焦点返回引用。上或下方向键从对应边缘打开菜单；方向键、Home、End 与前缀输入在当前菜单的可用项目间移动；右和左方向键进入与退出子菜单；Escape 关闭一层或根菜单；Tab 按所请求方向退出，而不是逐个访问每个菜单项。选择项目或关闭根菜单后会恢复焦点，除非所选操作已经明确把焦点移动到其他位置。

应用外壳把对话列渲染为 `main`，其中包含唯一一个本地化的应用一级标题。会话导航与已打开的会话详情是具名 complementary 地标。已关闭的详情内容继续挂载以保持状态，但会进入 inert 状态并从无障碍树隐藏。两个可见缩放把手都是具名、可聚焦、带范围与当前值元数据的垂直 separator；左／右方向键按面板的物理边缘调整宽度，Home 选择最小宽度，End 选择最大宽度，Shift 使用更大步长。外壳 overlay 与 separator 都保留在 main 地标内。

Workspace 浏览器为每棵非空的分组树、扁平树或搜索结果树分别保留一个漫游 Tab 入口。上／下、Home／End 在已渲染行间移动；Enter 与空格激活聚焦行。显式编写的 `aria-level` 元数据让右方向键可以打开或进入 Workspace，让左方向键可以将其关闭或从 Session 返回，而不必从展示层包装推断层级。只有活动行拥有的按钮才进入顺序导航。空容器不暴露 tree role。折叠的搜索输入框不在无障碍树中；Escape 与清除会把焦点还给始终存在的搜索按钮，外部指针关闭则保留用户的新焦点目标。

composer 模型位把两层选择器实现为只有一个顺序入口的菜单按钮。从边缘打开、方向键／Home／End 漫游、右方向键进入、左方向键或 Escape 返回、优先聚焦已选值，以及恢复触发器焦点，都留在拥有选择层级的组件内部。命令 `popupSelect` 拥有控制其具名 listbox 的搜索 combobox；DOM 焦点留在搜索框，同时由 `aria-activedescendant` 与 `aria-selected` 暴露 controller 当前唯一的筛选结果项。它的 overlay 把 controller 的焦点返回回调绑定到拥有当前弹窗的确切 composer 卡片，而不是查找任意常驻输入框。加载、应用、空结果与失败状态保持可发现，且不会把每条结果加入顺序 Tab 导航。

上下文占用率实现 disclosure 关系。触发控件暴露展开状态并控制稳定的面板 id；打开的面板是具名信息 region，而不是模态 dialog。Escape、外部指针操作或再次激活触发控件会将其关闭，并且不会把焦点移入面板。

Conversation shell 跨独立的 header 与 body slot 拥有 Session View 标签页模式。顺序 Tab 导航中只有活动的 Chat 或 Trajectory 标签；左／右方向键循环，Home／End 移到边缘，移动时同时激活聚焦的 View。逐 Session 稳定 id 把每个标签连接到活动 `tabpanel`，面板名称再指回已选标签。

Trajectory 记录检查器为所选记录的可用详情拥有同样的自动激活标签契约。顺序导航中只保留一个活动标签；左／右方向键循环，Home／End 移到边缘，每个目标都会同时进入选中与聚焦状态。稳定面板由所有标签控制，并以当前标签命名。

Trajectory ledger 在已加载的逻辑记录中只拥有一个漫游行入口。上／下方向键逐条移动，Home／End 移到已加载边界；目标位于屏外时，先将其滚入虚拟挂载窗口再接收焦点。Enter 与空格激活记录或折叠摘要。内嵌 Request 控件只在活动行进入顺序导航；仅含 request 的分隔行继续保留自身显式控件。

Trajectory timeline 在记录时间条上拥有多选 listbox。DOM 焦点留在概览上，由 `aria-activedescendant` 暴露正在浏览的记录。方向键浏览，Shift 扩展闭合记录范围，Home／End 到达边界，Enter 或空格打开活动记录，Control 或 Command 加 A 选择已加载时间域，Escape 清除范围。键盘活动记录会在缩放视口间保持挂载并获得可视提示。

通用用户问题 composer 为每道单选题拥有具名的漫游 radio group。方向键循环，Home／End 到达边界，移动会选择目标但不改变当前题页；显式激活继续采用立即前进。因激活、翻页器导航、跳过或校验恢复而改变题号时，焦点会进入新题页已选中的 radio、首个 checkbox 或具名自定义字段。推荐信息和选项描述通过 `aria-describedby` 连接，不改变模型编写的选项名称。

## Alternatives considered

**通过 companion 插件修复渲染后的应用。** 拒绝，因为 MutationObserver 需要从不稳定标记推断职责，与 React 提交竞争，重复私有状态，并且仍无法保证嵌套焦点恢复或权威的 disclosure 状态变更。

**让每个菜单项成为普通 Tab 停靠点。** 拒绝，因为长菜单会占据顺序导航，并与复合 `menu` 交互模式冲突。漫游焦点只保留一个顺序入口，再由方向键操作整个集合。

**让每一条 Workspace 与 Session 行成为普通 Tab 停靠点。** 拒绝，因为较长的历史记录会占据顺序导航，并把一棵树拆成互不相关的停靠点。漫游行只保留一个入口，由方向键呈现有序层级；活动行的操作仍然可达。

**详情关闭时将其卸载。** 拒绝，因为外壳有意保留该子树及其状态。应用 `inert` 与 `aria-hidden` 可以在不改变生命周期的情况下移除已关闭控件的导航入口。

**继续把上下文占用率作为 dialog。** 拒绝，因为它既不接收焦点，也不阻塞应用。控制具名 region 的 disclosure 符合实际交互，并且不会播报并不存在的模态行为。

## Verification

70 个聚焦 jsdom 测试覆盖弹窗栈、初始与约束焦点、背景 inert、已断开连接的打开控件、空弹窗、包括 Tooltip 包裹触发控件在内的菜单按钮归属、边缘打开、漫游按键、前缀输入、子菜单、Tab 退出、具名地标、关闭详情排除、分隔条元数据与缩放，以及上下文 disclosure 归属。完整 GUI 测试通道有 288 个文件、3,830 个测试通过，1 个测试按既有条件跳过。

76 个聚焦 Workspace 行与浏览器测试通过；行源码的语句、分支、函数与行覆盖率均保持 100%。构建后的应用随后在 Chromium（6 个测试）、Firefox（5 个测试通过，跳过仅限 Chromium 的强制颜色用例）与 WebKit（5 个测试通过，同样跳过该用例）中通过同一套真实种子会话树层级、漫游焦点、disclosure 按键、搜索焦点返回、模型菜单键盘路径、命令 combobox 归属与焦点返回、窄屏回流、焦点可见性、设置弹窗约束、强制颜色与减少动态效果检查。

23 个聚焦模型位与命令弹窗测试通过，覆盖从边缘打开、单入口菜单焦点、进入与返回子层、当前项焦点、combobox 归属、active-descendant 同步、精确 composer 绑定、选择、取消、错误与焦点恢复路径。

22 个聚焦 Conversation shell 测试通过，覆盖具名的漫游 View 标签列表、方向键／Home／End 激活与循环、稳定的标签到面板关系，以及活动面板的顺序焦点入口。

37 个聚焦 Trajectory table 测试通过，覆盖 ledger 的单入口行停靠点、跨虚拟滚动边界的逻辑方向键／Home／End 移动、活动行 Request 操作归属，以及详情检查器的单入口标签停靠点、激活、焦点移动和活动标签到面板关系。33 个组装 Trajectory view 测试包含多选 listbox 归属、active-descendant 浏览、Shift 扩展范围、打开记录、选择整个时间域与集成 ledger 路径；合计 70 个聚焦测试通过。

17 个聚焦用户问题 composer 测试通过，覆盖具名的单入口 radio group、不翻页的方向键／Home 循环选择、推荐和描述关系、进入下一题自定义字段的焦点连续性、IME 安全输入、校验恢复、取消、失败后重新启用，以及 Session 级草稿恢复。

生产构建完成后，组装 Web replay 的 93 个文件中有 92 个通过、1 个按条件跳过；311 个测试通过、15 个跳过。经过审查的无障碍树 golden 新增应用 `main`、其中的一级标题、具名会话导航 complementary 地标、键盘分隔条与具名菜单，同时移除已经折叠的详情子树中的控件。契约类型检查、契约 lint 与 Node 22 文档测试通道也通过。这些检查验证 DOM、焦点、构建后组合与浏览器无障碍树契约；它们不能认证真实朗读或真实辅助技术操作。

## Deferred

这项决策不宣称 Web 已完整适配无障碍。Timeline listbox 与范围的真实朗读、模型选择与命令弹窗的真实朗读、问题表单播报与 plan-review 使用方证据、对话 log 与完成播报、工具 disclosure、对比度与强制颜色行为、缩放与回流、减少动态效果、浏览器覆盖，以及任务级 VoiceOver、NVDA、JAWS、Narrator 与 Orca 证据仍属于需要分别验证的工作。

## Consequences

共享基础组件、Workspace 浏览器与外壳承担显式键盘、焦点、命名、层级和隐藏内容状态，包括比仅指针行为更复杂的嵌套职责。作为回报，无障碍契约与可见交互使用同一生命周期和状态权威，无需可选包即可工作，也能脱离展示层选择器进行回归测试。自动化组件检查是必要证据，但不足以支持完整无障碍声明。
