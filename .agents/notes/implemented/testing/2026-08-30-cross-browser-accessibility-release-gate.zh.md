# Agent Note: 跨浏览器无障碍发布门禁

Status: implemented

[English](2026-08-30-cross-browser-accessibility-release-gate.md) | 中文

## Problem

Web 应用已有语义单元测试和 Chromium 浏览器快照，但没有必过发布门禁在多个浏览器引擎或访问模式下验证无障碍行为。一次变更可能保持宽屏 Chromium 快照不变，却让 WebKit 键盘无法到达 Settings、窄视口中的焦点被裁切、某个 Settings 面板发生溢出、减少动态效果偏好失效，或系统颜色不可用。

这个缺口还会混淆证据声明。浏览器自动化可以发现可重复的符合性回归，但无法证明读屏用户能够完成真实 DSH 任务，无法证明某个辅助技术与操作系统组合端到端可用，也无法证明残障参与者认为工作流能够独立、有效且安全地完成。

## Decision

新增聚焦的组装后应用无障碍测试套件，并在 Playwright Chromium、Firefox 和 WebKit 中串行运行。该套件启动随附的 Web scaffold，使用确定性会话回放，并验证以下发布关键行为：

- 有名称的应用 landmark 与核心控件；
- 在 640 与 320 CSS 像素下等效验证 200% 与 400% 回流，文档和 Settings 面板均不产生水平溢出；
- 完整的键盘 Settings 路径、可见且未被遮挡的焦点、模态焦点约束、Escape 关闭和焦点恢复；
- 在窄视口中遍历每一个已注册 Settings 区域，而不只验证初始选中区域；
- 在 Chromium 中验证 Windows 强制颜色；以及
- 在减少动态效果偏好下保留核心信息和控件。

测试套件使用各平台向真实用户提供的键盘约定。当宿主机未启用完整键盘导航时，macOS WebKit 使用 Option+Tab；其他受测组合使用 Tab。这样既保留纯键盘断言，也不修改宿主机偏好或为原生控件添加多余的 `tabindex`。

PR 工作流安装 Web 包所拥有版本的浏览器，并在独立、必过的 `node-24-accessibility` job 中运行该套件。汇总判定依赖此 job，因此浏览器专属或访问模式回归会阻止合并。托管 runner 安装浏览器系统依赖；持久化 failover 镜像只安装浏览器 payload。

该门禁是版本化无障碍证据模型的一层。它可以支持自动化浏览器结果，但不得被表述为真实辅助技术或残障用户证据。发布与支持声明继续记录准确的 DSH 版本、操作系统、浏览器、辅助技术及版本、任务脚本、结果、严重程度、测试者角色和证据日期。

## Alternatives considered

**仅依赖组件测试和无障碍树快照。** 这些测试速度快并保留包所有权，但不会验证浏览器焦点导航、视口几何、媒体模拟或组装后的 shell。

**在三个引擎中运行完整 Web 快照语料。** 这会成倍扩大宽泛的 consumer lane，并产生大量引擎专属渲染变动。聚焦的不变量套件让失败具有明确的无障碍含义，同时让现有快照语料继续负责其录制会话契约。

**只使用自动规则扫描器。** 规则扫描器可以发现有价值的标记与对比度问题类别，但无法证明键盘任务完成、模态焦点行为、窄面板回流或焦点可见性。它们是补充证据，而不是充分证据。

**在 WebKit 测试前全局配置 macOS 键盘导航。** 修改宿主机偏好会使本地运行带有状态，并可能影响无关应用。使用面向用户的键盘约定可以保持测试隔离，并覆盖偏好未开启的路径。

## Invariants

- Chromium、Firefox 和 WebKit 都运行同一套组装后应用语义、回流、焦点和减少动态效果契约。
- 不受支持的媒体模拟必须显式限定引擎；它不得静默跳过该引擎其余无障碍门禁。
- 320 CSS 像素路径会访问每个已注册 Settings 区域，并根据视口和命中测试表面检查每个抽样焦点目标。
- 通过键盘验证打开、模态焦点约束、Escape 关闭和焦点恢复，不使用指针作为后备。
- PR 必过汇总包含无障碍浏览器 job。
- 浏览器自动化与真实辅助技术、残障用户证据分别标注。
- 门禁通过本身绝不授权“完全无障碍”声明。

## Consequences

窄屏 shell 与 Settings 模态框现在会回流，不再把控件压缩到不可用的窄列中。Settings 复用共享模态框 primitive，以获得背景 inert、焦点陷阱、Escape 处理和焦点恢复。折叠导航在各引擎中保留可访问的 Settings 名称，窄屏折叠不再让焦点滞留在过渡动画之后，获得焦点的 Settings 控件会完整滚动到视口内。

贡献者会获得指出浏览器和被违反几何或交互不变量的聚焦失败。新增必过 job 会为每个 PR 增加一次构建和三次短浏览器运行，同时让失败与更大的快照和 artifact lane 保持独立。

## Risks

Playwright WebKit 是较新的 WebKit 构建，而不是品牌版 Safari；Linux 上的 WebKitGTK 也不等同于 Apple 平台 WebKit。因此本地 macOS 证据与必过 Linux CI 相互补充，但不能替代 Safari 加 VoiceOver 的任务运行。

几何和媒体模拟检查仍可能遗漏语音输出、盲文显示、读屏交互模式、认知负荷、时间压力、破坏性操作理解和错误恢复。扩大支持声明前，仍必须提供版本化手动脚本、真实辅助技术结果和残障参与者证据。
